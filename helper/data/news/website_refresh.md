You may have noticed: the website has had some changes, hopefully making it more responsive on mobile formats.

Of course, with such widespread updates, there may be some unexpected behavior. If you run into any issues, please report them to me
in our community discord so I can fix them.

And of course, if there are any updates you'd like to see to the website, don't hesitate. 

One of the items I'd really like to work on next is providing more SSO (single sign in) options besides just discord. The top of the list is google,
but there are a few hoops I'll need to jump through to make that happen. When I get enough options that our users feel comfortable, I'd like to remove
the legacy login feature. This will require a bit of migration if you don't want to lose your data, but we can work on that!
